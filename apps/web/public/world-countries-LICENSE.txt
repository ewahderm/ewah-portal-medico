Natural Earth states that its vector and raster map data are in the public
domain and may be used in any manner; attribution is not required. Its terms
of use: https://www.naturalearthdata.com/about/terms-of-use/
The Natural Earth Vector repository README also describes Natural Earth as
public-domain map data: https://github.com/nvkelso/natural-earth-vector

Optional suggested credit: “Made with Natural Earth.”

The client asset retains only feature names, available ISO-2 codes, and
geometries. ISO_A2_EH is preferred, with ISO_A2 as fallback. The two source
features without a valid ISO-2 code (N. Cyprus and Somaliland) have no iso2
property; no codes have been inferred.
