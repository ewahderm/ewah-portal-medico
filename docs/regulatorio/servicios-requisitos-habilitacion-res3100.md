# Servicios y requisitos de habilitación — Resolución 3100 de 2019

Compartido por el usuario el 2026-10-06 como insumo para el futuro **módulo de Habilitación** (ver memoria `resolucion_3100_habilitacion.md`). Es un resumen aplicado — ejemplos de prácticas médicas concretas dentro de cada grupo/servicio REPS, con los requisitos de personal, dotación y documentación que exige la resolución — no una transcripción literal del texto legal. Antes de convertir cualquier fila en una regla de validación dura del sistema, confirmar el detalle exacto contra el PDF oficial (`minsalud.gov.co/sites/rid/Lists/BibliotecaDigital/RIDE/DE/DIJ/resolucion-3100-de-2019.pdf`, ya usado para sembrar el catálogo `practicas_medicas` en la migración `0055_servicios_habilitados.sql`).

| Grupo de Servicio | Servicio (ejemplos principales) | Complejidad | Documentación, personal y requisitos (Res. 3100) |
|---|---|---|---|
| Consulta Externa | Medicina General | Baja | Título de médico general, inscripción en RETHUS. Dotación básica: tensiómetro, fonendoscopio, báscula, camilla, cinta métrica. Guías de Práctica Clínica (GPC) adoptadas. |
| Consulta Externa | Odontología General | Baja | Título de odontólogo, RETHUS. Unidad odontológica completa, compresor, protocolo de bioseguridad y esterilización, amalgamas/resinas. Licencia si tiene RX. |
| Consulta Externa | Pediatría | Media / Alta | Título de especialista en Pediatría, RETHUS. GPC para atención infantil, báscula pediátrica, infantómetro, cintas métricas, dotación básica. |
| Consulta Externa | Cardiología | Media / Alta | Título de especialista en Cardiología. Electrocardiógrafo. Protocolo de lectura y entrega de resultados oportunos. GPC para riesgo cardiovascular. |
| Consulta Externa | Enfermería | Baja | Título de enfermera(o) profesional. RETHUS. Insumos para curaciones, retiro de puntos, promoción y prevención. |
| Consulta Externa | Psicología | Baja | Título de psicólogo clínico. Área que garantice privacidad acústica y visual. Pruebas psicométricas (si aplica) con derechos de uso. |
| Apoyo Diagnóstico | Laboratorio Clínico | Baja / Media / Alta | Título de Bacteriólogo o Microbiólogo. Constancia de control de calidad interno y externo. Calibración de equipos. Cadena de frío (neveras y termohigrómetros). PGIRASA. |
| Apoyo Diagnóstico | Imágenes Diagnósticas (ionizantes) | Baja / Media / Alta | Licencia de práctica médica vigente. Oficial de radioprotección. Dosimetría de personal. Título de Tecnólogo en radiología y Médico radiólogo (Media/Alta). Blindaje aprobado. |
| Apoyo Diagnóstico | Imágenes Diagnósticas (no ionizantes — ecografías) | Baja / Media | Título de médico especialista con entrenamiento certificado. Ecógrafo con transductores adecuados. Medio de contraste y carro de paros (si aplica). |
| Apoyo Diagnóstico | Toma de Muestras | Baja | Personal con certificado en toma de muestras. Sillas para toma de muestras. Insumos rotulados, ruta de transporte de muestras y convenio de procesamiento. |
| Apoyo Diagnóstico | Servicio Farmacéutico | Baja / Media / Alta | Director Técnico: Químico Farmacéutico (Media/Alta) o Regente de Farmacia (Baja). Termohigrómetros calibrados, actas de recepción técnica, áreas separadas (cuarentena, aprobados, controlados). |
| Apoyo Diagnóstico | Fisioterapia / Rehabilitación Física | Baja | Fisioterapeuta con RETHUS. Equipos biomédicos (ultrasonido, TENS, etc.) con mantenimiento. Colchonetas, bandas, protocolo de desinfección de equipos. |
| Internación | Hospitalización Adultos | Baja / Media / Alta | Enfermera(o) profesional y auxiliar de enfermería 24/7. Sistema de llamado al paciente en cama y baño. Red de gases medicinales. Carro de paros por servicio. |
| Internación | Hospitalización Pediátrica | Media / Alta | Mismos de adultos + Especialista en Pediatría. Cunas/camas con barandas seguras. Ambiente y decoración amigable. Sala de juegos (deseable). |
| Internación | Cuidado Intensivo Adultos (UCI) | Alta | Intensivista presencial o disponibilidad. Equipo de monitorización continua invasiva y no invasiva, 1 ventilador mecánico por cama. Interdependencia con Lab Clínico, Banco de Sangre, RX y Cirugía 24/7. |
| Internación | Cuidado Intermedio Neonatal | Alta | Pediatra neonatólogo. Incubadoras de calor radiante, monitores neonatales, bombas de infusión (microgoteo), oxímetros neonatales. |
| Quirúrgico | Cirugía Ambulatoria | Baja / Media | Cirujano y Anestesiólogo. Sala de cirugía (tamaño normativo), revestimientos epóxicos. Máquina de anestesia, mesa, lámpara cialítica. Área de recuperación (RPA). Lista de chequeo de cirugía segura. |
| Quirúrgico | Cirugía General / Especializada | Media / Alta | Equipos de cirugía de alta complejidad (torres de laparoscopia, bisturí armónico, etc.). Convenio o área propia de esterilización (central de esterilización validada). UCI de respaldo (para alta complejidad). |
| Atención Inmediata | Urgencias | Baja / Media / Alta | Médico presencial 24/7. Cursos de soporte vital (BLS/ACLS) y atención víctimas de violencia sexual. Sala de reanimación equipada (carro paros, monitor, DEA/desfibrilador). Consultorios de Triage. Gases medicinales continuos. |
| Atención Inmediata | Atención del Parto | Baja / Media | Médico general/especialista o Enfermera con entrenamiento. Sala de trabajo de parto, parto y recuperación (TPR). Mesa ginecológica, pinzas umbilicales, equipo de reanimación neonatal. Incubadora de transporte. |
| Atención Inmediata | Transporte Asistencial Básico (TAB) | Baja | Documentos del vehículo (SOAT, tecno-mecánica). Tecnólogo APH o Auxiliar con BLS. Camilla con anclaje, oxígeno, maletín de urgencias, inmovilizadores. |
| Atención Inmediata | Transporte Asistencial Medicalizado (TAM) | Alta | Médico capacitado (ACLS) + Tecnólogo APH/Auxiliar. Monitor desfibrilador, ventilador de transporte, bombas de infusión, medicamentos de urgencias y controlados. Inversor de corriente funcional. |
